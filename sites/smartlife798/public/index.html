设备与订单

  • 扫码或碰一碰

    扫设备二维码，或用手机 NFC 读取支持的慧生活卡片。

    常用设备可以收藏、置顶，打开列表即可查看状态。

    按时间查看使用记录，点开订单核对费用和支付状态。

安装与更新

从 GitHub 下载正式版 APK，支持 Android 7.0 及以上。

下载 Android APK
首次安装

在 Android 手机打开下载完成的 APK。若系统要求，临时允许浏览器或文件管理器安装应用，按系统提示完成安装后用手机号登录。

从 2.x 正式版更新

打开新版 APK 并按提示覆盖安装，可以保留本机应用数据。

从 1.x 旧签名版迁移

请先结束设备使用并核对账单，再卸载旧版、安装 2.x 并重新登录。卸载会清除本机常用、最近、置顶设备和设置。

下载遇到问题

前往 GitHub 最新发行页，在附件中选择文件名以 -release.apk 结尾的安装包。
